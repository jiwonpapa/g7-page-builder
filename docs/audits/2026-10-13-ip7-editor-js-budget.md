# IP7 편집기 JS 용량 기준 변경

2026년 10월 13일 사용자가 편집기 JS gzip 상한의 512,000바이트 조정을 승인했다. 기존 508,500바이트 대비 3,500바이트, 약 0.69% 증가다. 기존 편집기와 대체 v3 편집기 두 entry에 동일하게 적용하며 두 엔진을 동시에 로드하지 않는다.

공통영역 UI 결합 후보의 기존 편집기 JS는 508,591바이트로 이전 상한을 91바이트 초과했다. 이번 변경은 용량 정책 조정이며 최적화 성과나 성능 개선으로 보고하지 않는다. 관련 승인 답변은 “512,000바이트로 조정”이다.

범위는 `scripts/check-frontend-budgets.mjs`, `tests/Harness/test_frontend_budgets.py`와 이 감사 기록 세 파일이다. Node 24에서 이전 상한 초과·새 상한 이하의 샘플 허용과 두 entry의 새 상한 초과 거부를 검사한다. 공개 CSS는 앞서 승인된 측정 전용 정책을 유지한다. 그 외 JS/CSS·공개 runtime 합산 상한과 브라우저 성능·동작·시각 회귀 기준은 변경하지 않는다.

이 정책 검사는 브라우저 동작이나 IP7 완료를 증명하지 않는다. 소유된 공통영역 UI task가 변경 이력과 진척 증거를 함께 기록하며, 제품 통합 검사는 변경된 기준의 실제 번들을 다시 확인한다. G7 코어·운영 서버·기존 문서는 변경하지 않는다.
