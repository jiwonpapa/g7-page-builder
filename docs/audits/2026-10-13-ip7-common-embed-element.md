# IP7 공통 영상·지도 요소

상태: 초기 소스 `202a3e7538c16d7c7622944ad50cd3a8f00231a3` 공식 제출 후 보완 중이다. 첫 통합에서 설치 제품 30개는 통과했으나 독립 시험은 JS 용량 조건으로 실행 전 실패하여 통합이 원복됐다. 최종 통합·독립 브라우저 성공이나 IP7 완료 근거는 아니다.

## 범위와 사용자 경험

- `media.embed` 하나를 공통 문서 요소로 추가한다. 빈 캔버스와 임의 구성에서 동일한 Inspector·문서 명령·단일 Undo·반응형 디자인을 사용한다. 블록명별 편집기나 구성 변환기를 등록하지 않는다.
- 시각 원칙: 기존 작업면·공통 Inspector의 정보 밀도와 의미 토큰을 유지한다. 별도 장식 UI를 추가하지 않는다.
- 내용 원칙: 접근성 설명, 제공자, 영상 ID 또는 좌표·확대만 입력한다. 임의 iframe·HTML·URL·스크립트·인증 동작은 문서가 소유하지 않는다.
- 조작 원칙: 캔버스에서 외부 iframe은 포인터·키보드 입력을 가로채지 않는다. 외부 콘텐츠 조작은 미리보기·공개 페이지에서 수행한다. 잘못된 값은 공통 검증과 오류 표시로 거부하고 원본을 보존한다.

## 계약

기존 공개 제공자 YouTube, Vimeo, OpenStreetMap, Google 지도만 재사용한다. 미설정 상태는 네트워크 요청 없는 안내다. 영상 ID, 6자리 소수 정밀도의 위도·경도, 기존 확대 수준 12/14/16/18에서 URL을 생성한다. 문서의 임의 endpoint는 허용하지 않는다.

PHP와 TypeScript는 공통 schema·fixture의 허용/거부 및 정확한 URL 기대값을 사용한다. 공개 HTML의 iframe 금지 정책과 CSP는 유지하며 고정 runtime이 검증된 marker를 iframe으로 복원한다. 기존 구형 임베드 크기는 변경하지 않는다.

## 검증 경계

관련 단위/계약, 제출 gate, 독립 및 설치 제품 브라우저의 선택·입력·Undo·저장/재열기·발행·PC/태블릿/모바일 출력 일치는 각각 증거를 별도로 기록한다. 외부 제공자의 재생 가용성은 로컬 동작 증거와 구분한다. 기존 문서의 자동 전환·코어 변경·운영 배포는 범위 밖이다.

초기 사전 검사는 관련 프런트 34개, PHP 2개·284개 단언, 타입·구조를 통과했다. 첫 제출은 128개 계획 gate 중 runtime/browser를 Local 통합으로 이관했다. 실패 후 Inspector 좌표 입력을 기존 `TypedInput`으로 재사용하고 반복 옵션/URL 반환을 정리했다. 보완 후 임베드 관련 21개 테스트와 타입 검사가 통과했다. 제공자·주소·좌표 검증 의미는 유지한다.

첫 설치형 결과·실패한 독립 검사·UTF-8 시험 대역 보완·사용자 승인 JS 측정/경고 정책은 `docs/audits/2026-10-13-ip7-embed-product-proof.md`에 이어 기록한다. 제품 소스 task는 용량 정책·브라우저 시험의 다른 소유 파일을 변경하지 않는다.
