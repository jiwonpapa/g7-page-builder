# IP5 핸들과 다중 선택 작업면

상태: 구현 진행 중. IP4 완료 기준 `b8b90caca345284362fa8b9b65071ea70b63f91d`에서 시작한다. IP5의 단위·브라우저·접근성 증거가 모두 확보되기 전 완료로 집계하지 않는다.

## 구현 범위

첫 task `ip5-gesture-commands-20261012`는 v3 다중 스타일 명령과 측정값 기반 크기·좌표·회전·정렬/분배, 조작 시작 문맥 확인·표시용 초안·취소·한 번 확정을 담당한다. 문서 스키마·PHP 출력 의미·별도 Undo를 추가하지 않는다. 부모와 자식의 중복 선택은 루트에만 적용하고 잠금·다른 부모·상충하는 배치의 정렬은 원자적으로 거부한다.

다음 task에서 IP1의 정확 버전 Moveable 0.56.0·Selecto 1.26.3을 제품 의존성으로 승격하고, InteractionAdapter·캔버스·혼합값 Inspector·팬/줌·단축키를 연결한다. 공유 의존성 변경은 별도 task와 명시적 FULL 검사 사유로 처리한다.

## 화면과 입력 설계

기존 캔버스 중심 구성과 좌측 레이어·우측 Inspector를 유지한다. 선택 테두리·핸들·스냅 가이드만 조작 상태를 표시하고 장식 애니메이션은 넣지 않는다. 구조 DnD·정밀 조작·텍스트 입력은 명시적 모드로 입력을 나누며 모두 같은 문서와 Puck 이력을 사용한다.

50/100/200%·iframe/스크롤에서 저장 치수 일치, Esc/포커스 상실/문맥 변경 취소, 다중 변경 한 Undo, 텍스트 IME/키보드 보호와 저장·재열기를 실제 브라우저로 검증한다. 반응형 재정의는 IP6, 운영 저장/발행 연결은 IP9이며 이번에 앞당기지 않는다.

## 검증 기록

첫 task의 검증 결과와 제출·통합 SHA는 실행 뒤 기록한다. 제품 브라우저·접근성 합격은 아직 주장하지 않는다. G7 코어·테마·기존 발행본·운영 배포는 변경하지 않는다.
