선택 루트만 독립 v3 문서로 추출하여 사용자별 라이브러리에 저장·검색·재삽입한다. 저장 시 공통 copy/paste가 자산과 ID·동작·문의 내부 참조를 처리하고, 선택 밖의 fragment 링크는 누락시키지 않고 거부한다. 저장용 사본은 SEO와 site shell 소유권을 포함하지 않으며 원래 페이지를 변경하지 않는다.

새 테이블 또는 네이티브 편집 원본을 사용하지 않는다. 모듈 소유 사용자별 SectionPatternRepository를 사용하고 `section.document_json` 문자열에 검증한 v3 원본을 보존하여 Laravel 배열 cast가 빈 객체 의미를 바꾸지 않게 한다. 기존 패턴은 기존 기본 API 목록과 동작을 유지하며 새 편집기는 명시 v3 목록을 조회한다. DB row·기존 페이지·기존 Site Part를 자동 전환하지 않는다.

서버는 전체 v3 문서를 재검증한다. 라이브러리 조회·삭제는 기존 actor 소유 조회를 유지하고 기존 read/update/manage 권한을 재사용한다. 미지원 구성은 목록에 사유를 표시하여 삽입을 비활성화한다. 삭제는 해당 라이브러리 row만 지우며 사용 문서·미디어 파일을 삭제하지 않는다.

페이지 및 PB Header/Footer는 같은 UI·포트를 사용한다. 삽입은 기존 paste의 단일 Undo와 독립 사본을 사용하며 라이브러리 원본 수정·삭제가 삽입된 페이지로 전파되지 않는다. 비동기 저장이 다른 문맥에서 완료되면 서버에 저장된 사실과 현재 문서 무변경을 구분하고 자동 삽입하지 않는다.
