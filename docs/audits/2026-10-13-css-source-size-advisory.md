# CSS 파일 크기 비차단 정책

2026-10-13 사용자 지시에 따라 CSS 크기가 구현 중단 조건이 되지 않도록 소스의 줄 수도 비차단 경고로 전환한다. byte 측정 정책은 별도 제출 `74a77ba8af96b7c50d52904e37b976d51a8a71b1`과 결합한다. 제품 소스·스타일 내용·의존성·JS 상한은 변경하지 않는다.

`SOURCE-SIZE`의 CSS 1,000줄은 구조 검토용 경고다. CLI와 JSON 보고에 초과량을 남기되 종료 실패로 처리하지 않는다. CSS 문법·색 토큰·선택자·우선순위 검사와 TS/JS/PHP의 크기·부채 검사는 유지한다. 규범 문서의 이전 공개 CSS 상한 설명도 현행 정책으로 일치시킨다.

회귀 시험은 2,000줄 CSS의 경고와 CLI 성공, 같은 파일의 색상·중요도 위반 및 잘못된 문법 거부, 다른 언어의 크기 초과 거부를 확인한다. 공식 제출 `c5e4f0fc7703255cbb46b9f905ee777202eae56e`에서 관련 30개 시험과 정적 검사를 통과했고, byte 정책과 함께 `8ffe0698e70faba131ac017ada47156e58ba9a55`로 통합했다. 통합의 관련 25개 gate도 통과했다. IP7 기능 완료나 제품 브라우저 통과를 뜻하지 않는다. 최종 E2E 상한 및 CHANGELOG·진척 원장 정합화는 기존 소유 task 통합 후 별도 `css-browser-policy-record-20261013`에서 수행한다.
