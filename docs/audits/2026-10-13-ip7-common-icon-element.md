# IP7 공통 아이콘 요소 구현과 검증

`media.icon`은 구성 이름과 무관한 공통 기본 요소다. 기존 카탈로그의 신뢰된 아이콘 23종을 사용하며 임의 SVG·HTML·실행 코드를 문서 입력으로 받지 않는다. 새 구성 데이터는 같은 편집기 빌드에서 이 요소를 조합할 수 있고, 블록별 편집기 등록을 요구하지 않는다. IP7 전체 완료 판정은 별도다.

## 구현 범위

문서 props는 `icon`, `label`, `decorative`다. 의미 있는 아이콘에는 눈에 보이는 문자가 포함된 설명을 요구한다. 장식용 아이콘은 접근성 트리에서 제외하되 기존 설명을 원본에 보존한다. 색상·크기·반응형 값은 기존 typed 스타일 계약을 사용한다. 새 Inspector는 공통 content 명령을 호출하며 Puck의 단일 Undo·저장 경로를 공유한다.

React 편집/미리보기와 PHP 출력은 기본 24px 및 지정된 크기·색상을 따른다. PHP는 기존 신뢰된 아이콘 출력기를 재사용한다. 생성 SVG와 기존 안전한 복원 마커를 함께 제공하고, 공개 hydration은 명시적인 부모 크기 모드만 처리한다. 문서가 임의 마커 속성이나 실행 동작을 정의하지 않는다. 기존 아이콘 출력의 기본 모드는 변경하지 않는다.

공식 task `ip7-common-icon-element-20261013`은 기준 `71414ca21fe449c789158772d095e5eb88bc3ee0`에서 `shared-contract` lease와 정확한 파일 21개를 소유한다. 공유 문서 계약과 공개 runtime이 바뀌므로 제출·통합의 FULL 검사가 필요하다. G7 코어·기존 문서·운영 서버는 변경하지 않는다.

## 확인된 검사와 남은 검증

Node 24와 PHP 8.5.3의 직접 검사에서 Vitest 121개, TypeScript strict, PHPUnit 10개·637 assertions가 통과했다. TS/PHP는 같은 아이콘 수용·거부 fixture 8개를 사용한다. 23종 렌더, 의미 설명의 escaping, 빈 설명 거부, 임의 필드 거부, 공통 편집 명령과 반응형 원본 불변, 장식용/readonly Inspector, 공개 hydration의 안전한 크기 처리와 중복 실행을 포함한다.

독립 브라우저 시험은 빈 카탈로그 삽입, 의미·공통 스타일·모바일 편집, 단일 Undo/Redo, 주입 저장 포트 재열기와 23종의 세 폭 React/PHP 기하·색상·접근성 비교를 추가했다. 아직 실행 결과가 아니며 실제 서버 저장·발행 증거를 대신하지 않는다. 공식 제출 검사, Local 통합 및 설치형 저장·발행·G7 출력 후 아이콘 복원 시험을 이어서 수행한다. 통합된 공통영역 UI의 후속 증거 및 진척 원장·CHANGELOG 갱신은 해당 파일을 소유하는 별도 task에서 처리한다.
