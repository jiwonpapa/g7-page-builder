## 구현과 정책

- 글자 범위는 같은 블록 ID·필드 경로에서만 유지합니다. 다른 텍스트 요소 선택 시 이전 범위 표시를 해제하고, 이전 편집기의 늦은 해제 이벤트가 현재 범위를 지우지 않도록 대상 식별자를 전송합니다. 오래된 이벤트의 선택 메타 누락은 호환 처리하며 새 입력은 실행 시 형식을 검사합니다.
- 부모 복귀·대상 삭제·반복 항목 인덱스 소멸·권한 상실 시 도구와 대기 중 콜백을 정리합니다. Tiptap view가 해제된 상태에는 공개 `isDestroyed`로 접근을 보호합니다.
- 이미지/연결 선택창은 열었던 필드를 소유합니다. 대상 변경·창 해제 뒤 늦게 도착한 결과와 중복 적용을 거부합니다. 같은 대상은 Puck의 공개 `useGetPuck`로 읽은 최신 props에 값을 적용하여 다른 속성을 되돌리지 않습니다.
- 반복 항목과 내부 텍스트를 구별하고 항목 이동 시 해당 스타일 경로도 함께 이동합니다. native Puck 히스토리는 250ms 안의 연속 명령을 묶을 수 있습니다. 묶음의 원본과 결과 복원을 검증하며 클릭마다 독립 Undo를 보장하거나 별도 히스토리 엔진을 만들지 않습니다.
- 본문 반응형은 공통값 → 태블릿, 공통값 → 모바일의 독립 상속입니다. 스타일/레이아웃 초기화는 해당 부분만 지우며 모바일 Columns는 1열 고정입니다. Header/Footer 별도 계약과 구별합니다.
- 새 서버·풀 테마·신규 블록·원시 CSS/HTML/JS·G7 내부 의존성·새 편집기 엔진·스키마/API 변경은 없습니다. 다음 차수의 내부 슬롯/신규 요소를 이번 완료로 미리 세지 않습니다.
