# IP7 공통 폼 요소와 제출 연결

기준 SHA: `601d18d9b6e1ebd44dc93da22cd99f3586c7a2e6`. 계약 task: `ip7-common-form-contract-20261013`. IP7은 진행 중이며 화면·서버 연결을 포함한 전체 기능 완료가 아니다.

## 공통 편집 계약

`form.control`과 `form.label`은 구성 이름과 무관한 요소다. 입력 종류·설명·placeholder와 라벨 문구를 기존 content 명령으로, 디자인을 기존 style 명령으로 변경한다. 사용자 입력값·raw HTML·CSS·스크립트·제출 endpoint는 저장 원본에 넣지 않는다.

컨테이너의 `binding`은 고정 문의 capability와 입력·라벨·제출 버튼·상태 문구의 안정 ID를 연결한다. 기존 문의 서비스의 name/email/message/privacy 필수 항목과 phone/subject 선택 항목을 재사용한다. 폼 종류는 기존 inquiry/quote/reservation/application/newsletter로 제한한다. 인증·전송·보안 검사는 문서가 아니라 기존 서버/runtime이 계속 소유한다.

PHP와 TS는 같은 schema·정책·fixture를 검증한다. 잘못된 역할/참조, 중복 필드/요소, 필수 필드 누락, 중첩 폼, 제출 버튼의 상호작용 중복 소유를 거부한다. 전체 폼 복사는 모든 참조를 새 ID로 연결하고, 연결된 필드를 폼 밖으로 이동하거나 단독 삭제하면 원본을 유지한 채 거부한다. 연결 제거 후 구조 편집은 허용한다. 일반 요소 복사는 서비스 연결을 복제하지 않는다.

## 화면 연결 원칙

- 시각: 기존 작업면·Inspector와 의미 토큰을 유지하며 별도 폼 전용 편집기나 장식 UI를 만들지 않는다.
- 내용: 선택한 요소의 입력 종류·라벨과 고정 제출 역할을 보여 준다. endpoint나 실행 코드 입력란은 제공하지 않는다.
- 상호작용: 기존 선택·문서 명령·Puck 이력에 연결한다. Inspector의 적용/취소·잠금·오류와 키보드 포커스를 검증한다. 편집 화면의 임시 입력은 저장 문서를 바꾸거나 전송하지 않는다.

## 계약 검증

로컬 Node 24/PHP 8.5.3에서 폼 계약 35개와 내장 구성/source graph 2개, PHP 2개/64 assertions, 구조 검사 8개 파일을 통과했다. 확장 제출 검사에서 발견한 검증→트리→검증의 순환 import는 검증 내부 순수 순회로 제거했다. 공통 fixture의 양 언어 검증 외에 불변 명령, 잘못된 작업의 원자적 거부, 자손 잠금, 복사/붙여넣기의 참조 재연결을 확인했다. 실제 Puck Undo·화면·저장/발행·공개 제출 증거는 후속 연결 task에서 별도로 확보한다.

이 계약 제출과 화면/출력 연결은 서로 의존하므로 단독 제품 통합하지 않는다. 범위가 겹치지 않는 후속 task와 공식 batch 검증으로 통합한다. 기존 문서의 자동 이행이나 G7 코어·운영 서버 변경은 포함하지 않는다.
