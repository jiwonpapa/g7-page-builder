# 6차 대표 콘텐츠 제품화

## 시각·콘텐츠 방향

- Visual thesis: 현장 사진과 넓은 여백을 중심으로, 전문 서비스의 신뢰와 실행력을 차분하게 전달합니다.
- Content plan: 대상과 가치가 분명한 Hero → 실행 기준 3개 → 일하는 방식 → 서비스 단계 → 문의 CTA 순서로 읽힙니다.
- Interaction thesis: 기존 블록의 진입·hover·반응형 전환만 사용하며 프리셋 전용 모션이나 새 레이아웃 타입은 추가하지 않습니다.

## 6-A 대표 프리셋 6개

`hero.service-intro`, `rich-text.article-intro`, `image-text.company-story`, `features.core-benefits`, `card-grid.services`, `cta.contact`의 지시문형 샘플 문구를 실제로 읽히는 전문 서비스 문맥으로 교체했습니다. Hero와 회사 이야기에는 저장소가 제공하는 현장 이미지를 연결하고 구체적인 대체텍스트를 넣었습니다.

기술 상태는 `technical-rework-complete-human-review-pending`입니다. 문구 구조, 필수 링크, 미디어 존재, 컬렉션 항목 수는 자동 검사하지만, 미적 완성도·이미지 권리·실제 사업 수치와 최종 카피 승인은 사람이 결정합니다.
