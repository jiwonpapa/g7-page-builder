기준 SHA: `9bfef54023819ae83aaec85bdb4675c869764b52`. 구현 task: `ep1-placement-20260907`. 통합 task: `ep1-placement-integration-20260907`.

선택 위치의 실제 활성 슬롯을 기준으로 후보와 거부 이유를 표시하고, 클릭·이동·복제와 native Puck 입력의 최종 문서 검증을 같은 현행 부모/자식 계약에 연결합니다. 신규 기본 요소·복합 블록 내부 슬롯과 문서 schema 확장은 이번 범위가 아닙니다. CAT-02/INS-01/POL-01의 실제 증거를 확인한 후 완료 상태를 기록합니다.

## 구현과 현재 검사

- 구역/열/세로 묶음의 활성 슬롯만 위치로 사용합니다. 반복 props·미선언 배열·비활성 column3은 후보가 아닙니다. 명시적 위치 선택 없이 호환 불가 컨테이너 밖으로 삽입하지 않습니다.
- 라이브러리의 기본 후보/검색/제작 단위 수와 빠른 추가는 삽입 가능 여부를 따릅니다. 전체 확인에서는 버튼을 비활성화하고 이유를 표시합니다.
- 경로에 구역/열 묶음/세로 묶음의 순번을 표시하고 같은 선택 모델로 부모를 선택합니다. 기존 이동 메뉴와 실행 명령에서 잘못된 위치·순서·자기 하위·개수·깊이를 함께 검사합니다.
- 기본 Section의 4개 노드/3단계와 복제 subtree 전체를 계산합니다. 구조 편집을 사용하지 않은 v1에는 v2 한도를 소급 적용하지 않으며 등록된 외부 팩 root 삽입을 유지합니다.
- 초기 검사에서 제품 props의 동적 키 타입과 테스트 fixture 타입 narrowing, 새 경로 표시를 기대하지 않는 기존 문구 assertion을 보완했습니다. 제품 구조/카탈로그 규칙을 테스트 통과 목적으로 완화하지 않았습니다.

관련 TS 단위 57개를 먼저 확인했습니다. 최종 scoped 단위/PHP/브라우저 검증과 통합 결과를 아래에 연결하기 전에는 완료로 보고하지 않습니다.
