# IP8 첫 이미지 삽입 보완

기준 SHA: 3c02566748a0e57877017ac7a14f3ae9f1311acf. task: editor-empty-image-insert-20261013.

MEDIA02: 이미지 교체 UI의 소스 연결을 확인하는 중, 빈 v3 문서는 assets가 없고 기본 createPrimitive(image)는 자산을 요구하므로 이미지 Inspector에 도달하기 전에 첫 삽입이 거부되는 선행 경로 누락을 확인했다. 이미지 기능의 허용된 1회 보완으로 업로드·라이브러리·검증한 URL로 자산 등록과 노드 삽입을 한 명령으로 처리한다. 기존 primitive의 자산 검증은 완화하지 않는다.

선택·문서·session/edit revision·readonly·삽입 위치가 바뀌거나 취소된 요청은 현재 문서에 적용하지 않는다. 늦은 서버 업로드는 파일이 저장됐을 수 있으므로 삭제·원복을 주장하지 않는다. 새 노드 ID와 자산 충돌 검증 및 기존 한 Undo를 유지한다. URL은 공통 이미지 자산 문서 검증을 적용한다.

추가 시험 정의·E2E는 만들지 않는다. 최초 제출의 기존 선택 검사에서 실패하면 이 이미지 보완은 추가 재구현 없이 실패로 인계한다. 별도 재감사에서 빈 페이지 첫 이미지 삽입 3경로, Undo/Redo, 재열기/발행, URL/MIME 거부, 취소·문맥 전환·지연 응답을 확인해야 한다.
