새 `image` 문서 명령은 자산 등록과 이미지 교체를 원자적으로 기록한다. 같은 URL은 등록된 참조를 재사용하고 다른 URL을 같은 자산 ID로 덮지 않는다. 기존 스타일·반응형·이름·구조·노드 ID를 보존한다. 파일을 삭제하지 않으며 참조 제거와 서버 파일 삭제를 혼동하지 않는다.

업로드·목록 요청은 document/session/edit revision/node/readonly 문맥을 고정한다. 취소·다른 선택·Undo/Redo·문서 전환·잠금 또는 readonly 전환 뒤 응답은 적용하지 않는다. 취소된 업로드가 서버에 저장됐더라도 라이브러리에 보존하며 원복했다고 주장하지 않는다. 새 Undo 스택은 없다.

최초 구현 후 기존에 선택되는 비런타임 검사만 수행한다. 신규 E2E나 테스트 범위를 추가하지 않는다. 제품 수용 재감사에는 실제 업로드/교체→Undo/Redo→저장/재열기/발행, 3폭 초점·fit 일치, 지연·실패·취소·선택/문서/권한 전환, 미지원 MIME/URL, Header/Footer의 동일 기능을 포함한다. 사용자 구성 저장·재사용은 별도 잔여 구현이다.
