# IP7 전체 검사에서 독립 v3 브라우저 누락 방지

공통 Site Part 화면 통합의 공유 런타임 검사에서는 `FULL=1`이 필요하다. 기존 planner는 이때 제품 소스별 브라우저 매핑을 생략했다. 따라서 전체 제품 명령에 포함되지 않은 `structureEditorV3.spec.ts`와 `structureDocumentProduct.spec.ts`는 관련 제품 소스가 바뀌어도 필수 검사에서 빠질 수 있었다.

이번 범위는 `tools/g7pb/planner.py`, `tests/Harness/test_document_v3.py`와 이 기록 세 파일이다. 전체 제품 명령에 필터 없이 명시된 spec은 기존 전체 검사가 담당하며, 그 밖의 변경 소스에 매핑된 시나리오는 전체 검사 전에 실행한다. 기존 전체 검사와 시나리오·성능·시각 기준은 제거하거나 완화하지 않는다.

제출·통합·최종 확인·CI 네 단계에서 등록, 실행 의존성, 제출 시 실행 보류와 누락 spec 거부를 검사한다. `--grep` 등으로 제한된 명령을 전체 spec 실행으로 인정하지 않는다. 하네스 시험 통과는 검사 등록의 증거이며 실제 제품 브라우저 성공은 통합 실행으로 별도 판정한다.
