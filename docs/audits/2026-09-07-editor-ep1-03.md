# EP1-03 직접 편집·문맥 도구·설정 패널 연결

**진행 중: 1/4차 · 세부 작업 3/3.** [실행 계획](../productization/editor-plan.md)의 EDT-01/EDT-02/UND-01/SAV-01/RES-01을 대상으로 합니다. 총 4차수·11개 세부 작업이며 다음 차수는 2/4차 EP2-01 아이콘·목록·배지 삽입입니다.

## 단계별 커밋

1. 선택/설정 연결: `ep1-context-20260907`. 기준 `4c0d9938bfda4a297236e3b0cd38445b51073f95`. 범위 소유권·부모 복귀/삭제/권한 상실과 미디어/링크 선택창의 늦은 결과를 보완합니다. 실제 Puck 수명·문맥 단위검사와 실제 브라우저의 필드 간 직접 선택을 확인합니다.
2. 연속 명령/입력: 반복 항목·빠른 구조 명령 Undo/Redo, 한글 조합 입력, 저장 중 입력 보존과 지원 반응형 상속/초기화/출력을 확인합니다. 별도 scoped task로 커밋합니다.
3. 증거/진척 마감: 통합 SHA와 실제 검사 결과를 원장과 이 문서에 반영합니다. 아직 완료 증거를 선기록하지 않습니다.

## 경계

새 서버·풀 테마·신규 블록·새 편집기 엔진·원시 CSS/HTML 입력은 포함하지 않습니다. 기존 PC 편집과 반응형 미리보기 범위를 유지합니다. 배포는 요청되지 않았습니다.

## 확인 중 발견한 문제

- 기존 범위 상태는 다른 텍스트 필드로 바뀌어도 유지됐고, 단위검사도 이를 허용했습니다. 블록 ID/필드 경로가 같을 때만 유지하도록 수정했습니다.
- Tiptap view는 해제 상태에서 getter가 오류를 던집니다. 권한 전환 실제 Puck 검사에서 확인해 공개 `isDestroyed`로 view 접근을 보호했습니다.
- Puck의 기본 히스토리는 250ms 단위로 입력을 묶습니다. 빠른 명령의 데이터 보존과 native Undo/Redo를 검증하며 별도 히스토리 엔진을 만들지 않습니다.
