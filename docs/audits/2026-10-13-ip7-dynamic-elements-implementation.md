# IP7 공통 요소 동적 데이터 연결 구현 인계

2026-10-13 지시: 구현 진행, 검증 확대 금지, 추가 E2E/UX/성능 감사는 별도 보고로 인계, 문제별 재구현 최대 1회. 기존 문서 전환 제외.

- 게시글 목록/아카이브/상세와 상품 목록/쇼케이스/상세의 고정 공개 capability를 공통 `data` 연결로 표현합니다. endpoint, handler, live record는 문서 필드가 아닙니다.
- 원형 요소 트리의 모든 일반 구조·스타일은 기존 공통 편집으로 수정합니다. 공개 runtime은 그 트리를 복제하고 필드만 채웁니다. 이름별 DOM 생성/편집 함수를 등록하지 않습니다.
- TS/PHP는 같은 schema/policy로 소유 범위·역할·필드·참조를 검증합니다. 연결은 기존 문서 명령/한 Undo이며 복사/사용자 구성 재삽입은 참조 ID를 재배정합니다.
- 하나의 host 안에 하나의 원형을 배치합니다. 반복 안의 중첩 데이터·실행 컨트롤·문의 폼·상태 동작은 다중 live 소유를 막기 위해 거부합니다. 일반 요소/스타일 편집 제한과 구분합니다.
- editor는 작성한 원형 값, 서버 미리보기/발행 화면은 live 값을 표시합니다. 지연 응답과 제거된 화면은 기존 runtime 수명주기 검사를 재사용합니다.
- 제품 수용 미확인: 6개 capability 실제 응답·권한·빈 값·실패, 세 viewport의 작성 원형/반복 결과, UUID/내부 anchor, 저장 재열기/Undo, 검색·페이지 조작 보존. 새 시험 정의나 runtime 실행은 추가하지 않습니다.
- 아카이브/쇼케이스의 후속 페이지·검색/필터 UI는 이 변경의 일반 반복 필드로 구현하지 않았습니다. 기존 편집기의 해당 실행 컨트롤과 동등성은 재감사 필요 항목이며 전체 동등성 완료를 주장하지 않습니다.
