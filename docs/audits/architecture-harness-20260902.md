## 판정과 범위

**헌법을 실행 가능한 설계 검사와 연결하고, 검사 누락과 핵심 책임 집중·중첩 선택·테마 문제를 보완했습니다. 기존의 모든 구조 부채와 Visual UI Editor의 전체 기능을 완료한 상태는 아닙니다.**

진행 순서는 최초 감사 → 범위를 나눈 구현 → 독립 코드 검토 → 실제 통합 검사 → 재감사에서 발견한 누락 보완입니다. 문서 작성과 구현·시험·배포 증거를 구분했습니다. G7 Layout Editor의 코드·저장 엔진·내부 runtime을 의존성으로 추가하지 않았습니다.

제품 PHP/TS/CSS와 변경 검사 계획·실행기·규범 문서를 대상으로 했습니다. 전체 제품 소스의 정적 검사와 변경 경로의 정밀 검토를 수행했으며, 모든 함수·외부 Block Pack·전체 카탈로그 조합을 동작 검증한 감사는 아닙니다.

## 재검증 중 발견한 문제

1. 이전 브라우저 명령이 같은 결과 디렉터리를 재사용해 앞선 실패 자료를 지울 수 있었습니다. gate·입력·실행 UUID별 경로로 분리하고 실패→다른 gate→재시도 보존을 시험했습니다.
2. 기존 lifecycle은 제목에서 임시 contenteditable과 실제 입력기를 구분하지 않고, 재열기 시 부분 문자열만 비교했습니다. 실제 ProseMirror 준비와 정확 제목 검사를 적용한 후 발행·복원 흐름이 통과했습니다. 이 보완을 제품의 텍스트 병합 로직 수정으로 보고하지 않습니다.
3. 빠른 연속 조작은 Puck 0.23의 약 250ms history 기록 debounce로 묶일 수 있습니다. 저장된 상태 경계의 Undo 복구는 확인했지만, 모든 빠른 구조 명령을 각각 한 번의 Undo로 취소하는 보장은 아직 없습니다.
4. 규범 문서 목록과 guard의 실제 처리 목록 불일치를 발견했습니다. 7문서를 단일 config에서 선택하고 필수 목록의 누락·중복을 거부하도록 수정했습니다. Node에서 실제 Python planner를 호출하는 회귀의 의존 입력도 연결했습니다. 통합 `63c278bf0178364f36efccacea223ecbed9cd26f`의 9 gates, Node 24개·Python 77개와 제품 소스 213개 검사를 통과했습니다.
5. PHP 토큰 검증 일원화의 구형 저장 문서 읽기 호환 위험을 발견해 보완했습니다. 저장된 색상 값은 원본대로 읽고, 새 쓰기와 compile은 엄격하게 재검증합니다. 통합 `ac0b1c906e7414ab7eedb46c5beb3b394027023b`의 20 gates가 완료됐습니다. 관련 PHP 단위 156개/1,993 assertions, G7 SQLite·컨트롤러 통합 34개/390 assertions, core/G7 PHPStan 및 선택 브라우저 7개가 통과했습니다. 잘못된 값을 가진 실제 운영 DB를 조사하거나 운영 브라우저에서 열어본 결과는 아닙니다.

호환 회귀는 컨트롤러 조회 200과 원래 tokens/DB JSON·revision·lock 보존, 잘못된 새 쓰기 거부, 복원·preview·발행 준비 422, 마지막 정상 발행본 유지, 사용자가 값을 명시적으로 고친 뒤 저장되는 경로를 확인합니다. 저장 API의 기존 문서 계약 오류 400도 유지했습니다.

## 남은 작업과 완료 한계

- 45종 복합 블록 내부 구조 편집, 모든 중첩 이동·삭제·복제 진입점, 빠른 개별 명령 Undo는 별도 기능 구현과 인수 검증이 필요합니다.
- Puck 기본 drag/duplicate는 새 공통 삽입 사전검사를 거치지 않고 후단 v2 검증에 의존합니다. 후단 변환 실패의 UI 복구 경로도 별도 보완 대상입니다. 이번 TS 독립 검토에서 확인한 기존 경로의 위험이며, 한도 초과를 실제 브라우저에서 재현한 결과는 아닙니다.
- 렌더러별 분리와 XPath 제거, TS/PHP 디자인 정책의 공통 명세, 기존 CSS 부채 정리는 계속 필요합니다.
- 추출한 codec은 catalog 변환을 경유하므로 완전한 React 비의존 순수 커널이 된 것은 아닙니다.
- 사용자 블록 명칭·탐색 메뉴, 과도한 안내 배너, 짧은 옵션의 라디오 전환 등 전체 편집 UX 재기획은 이 기반 정비로 완료되지 않았습니다.
