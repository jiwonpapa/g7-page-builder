## 원본과 편집 경계

기존 RichText는 문단·제목·목록의 혼합을 저장합니다. 카드의 body/extra에서 목록 역할과 개수를 원본으로 판정해야 하므로 단순 목록을 별도 `content.list-01@1`로 결정했습니다. 기존 RichText와 IconList는 보존합니다.

아이콘은 기존 11종, 크기 3종과 의미 색상 3종입니다. 장식 아이콘은 숨김, 의미 전달 아이콘은 필수 접근성 이름을 제공합니다. 목록은 1단의 순서/비순서, 1~20항목, 항목당 일반 문구 200자입니다. 배지는 일반 문구 40자와 선택 아이콘을 갖는 정적 표시입니다. 링크·임의 SVG·HTML·JS·스타일·하위 슬롯은 받지 않습니다.

## 검증 상태

부품 단위 검증을 진행 중입니다. 라이브러리 삽입, 중첩 배치, 저장·재열기·발행, 세 화면 폭 출력의 성공 증거는 아직 없습니다. 새 서버·배포·풀 테마·단일 카드 개발은 이번 작업에 포함하지 않습니다.

- 새 block 3종·preset 3종으로 내장 정의 48종/프리셋 98종입니다. 호환 전용 HeroSplit 신규 삽입은 계속 숨깁니다. 일반 레이아웃의 기본 요소 허용 목록은 8종입니다.
