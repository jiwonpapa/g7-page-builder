# CSS 용량을 개발 차단 조건에서 제외

2026-10-13 사용자는 CSS 용량이 작업 중단의 병목이 되지 않도록 지시했다. 공개 CSS에 한정했던 측정 정책을 편집기·관리자·공통영역·모바일 내비게이션과 공통 기본 요소까지 적용한다. 원본 및 gzip 바이트를 기록하고 이전 상한 초과는 비차단 경고로 남긴다. 큰 임의 숫자로 상한을 옮기지 않는다.

CSS 파일의 존재·내용·문법과 import 소유권, 편집기에 관리자 전용 스타일이 섞이는 문제, 시각 회귀·실제 성능 검사는 계속 차단 조건이다. 이번 변경은 CSS를 추가하거나 전체 디자인·선택자·중복 스타일 규칙을 완화하지 않는다. 파일 분리와 최적화는 기능 구현 후 실제 측정과 유지보수 필요에 따라 수행한다.

`css-size-observability-20261013`은 기준 `59116bfa685959d5eb56bbedc629c8a6053eed12`의 정확한 파일 6개를 소유한다. 진행 중인 아이콘 통합 후보나 다른 task의 파일은 수정하지 않는다. 독립 E2E의 CSS 상한 제거와 변경 이력·진척 기록은 현재 소유 task의 통합이 끝난 뒤 별도 task로 연결한다. JS는 이미 승인된 두 편집기 512,000바이트 및 나머지 기존 기준을 유지한다.

검증은 이전 모든 CSS 상한을 초과하는 fixture의 정상 통과·실측 보고, JS 초과 거부, 누락/순환/import 경계·관리자 선택자 차단을 포함한다. 모바일 메뉴는 큰 CSS에서도 lint와 브라우저 명령을 실행하고 각각의 실패를 유지하는 격리 시험으로 확인한다. 격리 시험을 실제 제품 브라우저 통과로 보고하지 않는다. 공식 제출·통합 결과는 검증 후 기록한다.

직접 검사 `python3 -B -m unittest tests.Harness.test_frontend_budgets tests.Harness.test_content`의 56개와 `npm run typecheck`가 통과했다. Node 24를 사용했으며 실제 제품 브라우저 실행은 이 CSS 정책 검사에 포함하지 않았다.
