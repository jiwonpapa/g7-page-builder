# 모로 어드바이저리 · 전문서비스 킷 0.1.0

회사·컨설팅 제작자가 소개 → 제공 범위 → 진행 방식 → 상담 접수를 구성하는 킷입니다. 4페이지, 메뉴가 연결된 헤더·푸터 1세트, 이미지 3장과 설치 안내를 제공합니다.

현재는 유료 상품 후보의 평가용 패키지입니다. 판매 개시·가격·상업 이용 약관·지원 기간은 미확정이며 구매 완료나 정식 라이선스를 나타내지 않습니다. 자동 검증과 외부 제작자 평가·최종 디자인 승인은 별개입니다.

## 화면과 구성

시각 방향: 상담 장면을 크게 보여주는 첫 화면, 슬레이트 계열, 넓은 여백과 단정한 제목으로 전문서비스의 일관된 인상을 만듭니다.
내용 순서: 소개 → 서비스 범위 → 협업 과정 → 상담 요청. 예시 브랜드이며 가짜 후기·성과 수치·가격 약속은 넣지 않습니다.
동작: 기존 진입 모션·메뉴·FAQ·고정 문의 접수를 사용합니다. 새 모션 엔진이나 고객 서버 빌드는 없습니다.

| 페이지 | 구성 | 기본 주소 |
| --- | --- | --- |
| 소개 | 대표 이미지, 팀의 관점, 결과물, 상담 안내 | `/moro/about` |
| 서비스 | 제공 가치, 업무 범위, 상담 안내 | `/moro/services` |
| 진행 방식 | 협업 단계, FAQ, 상담 안내 | `/moro/process` |
| 문의 | 상담 준비 안내, 기존 문의 접수 폼 | `/moro/contact` |

홈 `/`는 바꾸지 않습니다. 추가 주소는 설치 화면에서 변경합니다. 전체 User Template 전환은 이 킷의 제공 범위가 아닙니다. 풀 테마 제작은 다음 개발 단계로 확정하지 않았으며, 현재는 소스 저장소의 `docs/productization/editor-plan.md`에 기록한 편집 고도화 실행계획에 따라 페이지빌더 편집 기능을 개선합니다.

## 설치 환경

PHP 8.5, G7 7.0.9, `sirsoft-basic 1.1.1`, 한국어, Page Builder 0.33.1 이후 **이 킷 선택 기능이 포함된 빌드**가 기준입니다. 같은 버전 번호의 이전 개발 빌드는 포함하지 않습니다. 전달받은 Git SHA/빌드 식별자를 확인합니다. manifest의 버전 상한은 호환 후보 범위이며 모든 조합의 시험 완료를 뜻하지 않습니다.

관리자 권한과 이미지 저장 경로 쓰기 권한이 필요합니다. DB·모듈 파일을 백업하고 검증된 사전 빌드 모듈을 사용합니다. 고객 서버에서 Node·npm을 실행하지 않습니다. stock G7 신규 설치 및 외부 VPS 평가는 별도입니다.

## ZIP 추가 → 초안 설치

1. ZIP과 `.sha256`을 같은 폴더에 두고 macOS `shasum -a 256 -c *.zip.sha256` 또는 Linux `sha256sum -c *.zip.sha256`으로 확인합니다.
2. 빈 폴더에 ZIP을 풀고 그 안에서 `shasum -a 256 -c SHA256SUMS` 또는 `sha256sum -c SHA256SUMS`를 실행합니다.
3. SFTP로 `module-files/resources/site-kits/professional-services-media/`를 서버의 `modules/jiwonpapa-page_builder/resources/site-kits/` 안에 먼저 추가합니다. 마지막으로 `professional-services.json`을 같은 `site-kits/` 안에 추가합니다. 상위 폴더 전체를 교체하거나 동기화 삭제 옵션을 사용하지 않습니다. 같은 파일이 이미 있으면 덮어쓰지 말고 버전을 확인합니다.
4. 관리자 **페이지 빌더 → 사이트 킷 → 모로 어드바이저리 · 전문서비스 킷 → 구성 선택**을 엽니다. 보이지 않으면 한국어 화면, 파일 경로와 체크섬을 확인합니다.
5. 설치 이름과 4개 주소를 정하고 **구성 확인**을 누릅니다. 기존 페이지·게시판·시스템 주소와 겹치면 다른 주소를 선택합니다.
6. **새 초안으로 설치**합니다. 기존 페이지와 활성 헤더·푸터는 유지됩니다. 통신이 끊기면 **설치 결과 다시 확인**을 사용합니다.

이 ZIP은 단일 페이지 내보내기 ZIP과 다른 파일 추가 패키지입니다. 원격 무료 스토어나 결제·라이선스 인증을 이용하지 않습니다.

## 수정 → 저장 → 미리보기 → 발행

1. 설치 결과에서 각 페이지를 열고 예시 브랜드·제목·본문·서비스 범위를 수정합니다. Hero 제목은 화면에서, 이미지·URL은 속성 패널에서 바꿉니다.
2. 각 페이지에서 **저장 → 새로고침 → 미리보기**를 확인하고 4페이지를 각각 발행합니다.
3. 문의 문구와 개인정보 안내를 운영 정책에 맞게 검토합니다. 테스트 접수를 관리자 문의함에서 직접 확인한 뒤 실제 상담 창구로 사용합니다. 문의는 메일 발송 여부와 관계없이 문의함에 먼저 보존됩니다. 메일 알림은 별도의 수신자·메일 서버 설정이 필요하며, 이 킷에서 이메일·CRM·예약 서비스를 설정해 주지는 않습니다.
4. **설치한 헤더·푸터 편집**에서 브랜드·메뉴·운영 주체를 바꾸고 세트를 저장·발행합니다. **적용**은 활성 User Template 전체의 공통영역에 영향을 주므로 페이지와 메뉴를 확인한 뒤 실행합니다.
5. PC·태블릿·모바일에서 메뉴 → 페이지 → 문의 경로와 줄바꿈·이미지를 확인합니다. 편집기는 PC에서 사용합니다.

설치 뒤 주소를 바꾸면 다른 페이지 버튼과 헤더·푸터 링크도 직접 수정해야 합니다. 자동 재연결은 없습니다.

## 지원·업데이트·복구

제공 범위: 위 구성과 기존 편집기의 문구·이미지·순서 수정, 설치·기본 호환 문제 확인. 맞춤 제작 대행, 업종별 기능 개발, 다른 템플릿 수정, 호스팅 운영, 외부 서비스 설정은 포함하지 않습니다. 유료 지원 기간·응답 시간은 판매 정책 확정 전 약속하지 않습니다.

업데이트는 새 이름·새 주소로 설치해 비교합니다. 설치된 문서와 업로드 이미지는 모듈 소유 데이터로 저장되며, 킷 파일·판매 서비스가 없어도 무료 편집기로 계속 수정할 수 있습니다.

공통영역 복구는 **이전의 정상 발행 세트를 다시 적용**합니다. 새 페이지는 관리 화면에서 발행 취소하고 추가 주소 상태를 확인합니다. 킷 파일 삭제만으로 발행 상태를 되돌릴 수 없습니다. 모듈 업데이트가 선택형 킷 파일을 제거하면 동일 패키지를 다시 추가합니다. 기존 설치 문서는 유지됩니다.

문제 보고에는 G7·템플릿·PHP·모듈 버전/빌드, 킷 버전, 실패 단계와 오류 문구, 개인정보를 지운 화면을 포함합니다. 비밀번호·토큰·접수 원문은 보내지 않습니다. 접수 채널은 평가 배포자가 안내합니다.

## 자산과 상품 전달

이미지는 저장소의 기존 ImageGen 기반 무료 Page Kit 자산을 재사용한 예시 장면입니다. 실제 직원·고객·실적이 아닙니다. 상품 가치는 독점 사진보다 페이지 구성과 설치·편집 시간 절감에 둡니다. 최종 판매 전 자산 배포 권한·브랜드·문구를 검토해야 합니다.

다운로드: `jiwonpapa-professional-services-0.1.0-evaluation.zip`, 외부 SHA256, 내부 전체 파일 SHA256, `PRODUCT.json`, 설치 안내와 무료 베타 안내. HTML·발행 토큰·사용자 데이터·Puck 상태·PHP 실행 코드는 넣지 않습니다. 버전별 파일은 덮어쓰지 않습니다.

판매 전 확정할 운영 항목: 가격, 세금 처리, 허용 사이트 수·제작 대행 범위, 원본 재판매 범위, 업데이트·지원 기간, 구매 전달·재다운로드 방법, 환불 정책, 자산 검토 결과. 현재 약관 또는 법률 적합성 승인으로 해석하지 않습니다.
