# IP6 반응형 상세 편집

상태: **구현 착수, 필수 동작 검증 전**. IP5 완료 기준 `8fb7508484214ec350225596249bd0969f46ce29`에서 시작한다. 계획 완료 수는 5/10이며 IP6를 아직 완료로 집계하지 않는다.

## 범위

기존 v3 문서의 base·tablet·mobile 독립 상속을 편집 화면에 연결한다. PC 공통값과 태블릿·모바일 전용값을 명시적으로 선택하고, 선택한 화면의 Inspector·다중 속성·핸들·표시 여부를 같은 문서 명령과 Puck 이력으로 변경한다. 속성별 초기화와 현재 화면 스타일 전체 초기화를 구분한다. 구조·텍스트 내용은 모든 화면에서 공유한다.

문서 스키마·의존성·G7 코어·기존 문서 전환·운영 저장 및 발행 연결은 변경하지 않는다. IP7 카탈로그 확장과 IP9 운영 저장 연결은 후속 범위다.

## 합격 조건

- 공통값 독립 상속, 0·false 재정의, 개별/전체 초기화, 잠금·읽기 전용, 다른 화면 값 보존을 관련 단위 시험으로 검증한다.
- 데스크톱 host에서 360·768·1280px 캔버스를 직접 편집한다. 화면 전환 중 미확정 조작은 다른 화면에 적용하지 않으며 Undo/Redo와 주입 저장 포트의 재열기로 문서 전체를 비교한다.
- 639·640·1023·1024px 경계와 세 대표 폭에서 편집 캔버스·React 미리보기·PHP 초안 출력의 치수와 스타일을 비교한다. 허용 오차는 1 CSS px다.
- Flex 방향·gap·Grid·크기·표시를 화면별로 검증한다. DOM 순서는 공통으로 보존하고 시각 순서와 읽기/키보드 순서가 달라질 수 있는 배치에는 경고를 표시한다.

## 검증 기록

착수 시 Local main은 깨끗했고 진행 중인 별도 README task는 수정하지 않았다. 통합이 끝난 깨끗한 managed worktree를 재사용한다. 구현과 시험 결과 및 제출·통합 SHA는 실제 확인 후 이 절에 추가한다.
