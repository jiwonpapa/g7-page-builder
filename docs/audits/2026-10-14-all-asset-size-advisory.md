# 모든 JS·CSS byte 상한 폐기

2026-10-14 사용자 지시: 기능 구현을 byte 초과 때문에 중단하지 않는다. 기존 편집기 JS/CSS 측정 정책을 관리자·공개 runtime 개별/합계·보존 네이티브·독립 IP1 호스트까지 통일한다. 종전 값은 경고 기준이며 새로운 상한이 아니다.

정확한 7파일 범위: 두 자산 검사기, 기존 합성 회귀, IP1 실행 정의, 개발 헌법, 변경 이력, 이 기록. 제품 기능·G7 코어·테마·기존 사용자 문서·JSON 데이터 입력 제한·소스 구조 기준은 변경하지 않는다. 이전 결과 보고서의 공개 JS 957바이트 초과는 과거 정책에서의 실측으로 보존하고, 현재는 차단 사유가 아니다.

초과 fixture는 정상 반환·raw/gzip 보고·경고를 확인한다. 파일 누락·빈 JS·의존성 경계·CSS 소유권 등 실패는 유지한다. 이 정책 검증은 제품 전체 E2E/UX 수용을 의미하지 않는다. 배포는 별도 공식 경로와 실제 원격 artifact/smoke 결과로만 판단한다.
