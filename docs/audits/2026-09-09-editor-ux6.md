# 독립 PB 개선 6차 — Hero·ImageText 버튼 구역

상태: 구현 중. 운영 미배포.

## 고정 범위와 소유권

사용자가 구조 편집 상태에서 `버튼 구역으로 편집`을 누를 때만 기존 primaryCta/primaryLink 문구·URL·지원된 문구 스타일을 Buttons 항목으로 옮긴다. 부모의 기존 버튼 입력은 숨기고 단일 Puck replace가 전환 및 Undo를 소유한다.

원본은 `g7-page-builder/v2`의 명시적 `slots.actions`다. 빈 배열도 소유권을 유지한다. 편집기 내부 actionsEnabled는 이 슬롯 존재에서 복원하며 별도 영속 필드가 아니다. 기존 block_version=1 속성 형식은 바꾸지 않고 선택형 슬롯을 추가한다. 이전 문서를 여는 것만으로 스키마나 버튼을 변환하지 않는다.

기존 props와 actions를 동시에 소유한 입력은 TS/PHP 구조 정책과 컴파일러가 거부한다. 기존 extra·본문·이미지·ID는 보존한다. 버튼 구역은 Buttons 0~1개, 항목은 기존 1~3개를 사용한다. 전체 깊이와 개수 제한을 유지한다. 삭제 이후 저장·재열기에서 기존 버튼을 복구하지 않는다.

## 완료 기준

관련 단위 검사, 실제 브라우저의 기존 문서/전환/편집/삭제/빠른 Undo/저장·재열기/미리보기·발행/읽기 전용을 확인한다. 새 콘텐츠·킷·테마·운영 배포는 범위 밖이다.
