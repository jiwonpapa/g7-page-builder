# 독립 PB 개선 5차 — 단일 Card 내부 구성

상태: 5차 구현·로컬 통합 완료. 관련 브라우저 19건 통과. 운영 미배포.

## 범위

`content.card-01`은 CardGrid와 별개의 단일 Card다. media에는 Image, body에는 Heading/RichText/Icon/List/Badge/Divider, actions에는 Buttons를 종류별 0~1개 배치한다. Buttons의 기존 1~3개 제한을 유지한다. 루트 또는 Section/Columns/Stack의 허용 위치에서 사용하며 전체 자식 포함 깊이 4를 넘는 구성을 거부한다.

내부 요소는 기존 Puck 트리·명령·필드·이미지/링크 picker·Undo를 사용한다. 같은 캔버스와 Outline에서 선택·추가·편집·순서 변경·삭제한다. Card 전체에는 링크를 부여하지 않는다. 링크는 내부 요소가 소유하며 중첩 링크를 만드는 카드 래퍼를 추가하지 않는다.

짧은 외형 설정은 기존 라디오 컨트롤을 사용한다. 카드 기본 틀은 편집/공개 화면이 공유하는 CSS와 페이지 의미 토큰을 사용한다. 외부 G7 편집기나 G7 코어 변경은 없다. 디자인 킷·새 테마·다른 컴포넌트 actions 확장은 제외한다.

## 검증 기준

- TS/PHP: 슬롯 허용 종류·개수·깊이, 잘못된 카드 속성 거부, 자식 ID/메타데이터와 명시적 빈 슬롯 보존.
- 실제 브라우저: 라이브러리에서 루트와 열 안에 Card를 추가하고 8종 내부 요소를 삽입. 내용 편집·순서 변경·삭제·빠른 Undo·저장·재열기·미리보기·발행을 확인.
- 편집 캔버스의 링크 클릭은 이동하지 않고 태블릿 미리보기에서는 구조 조작이 비활성화되어야 한다.
- 카탈로그와 썸네일 등록은 이 구조형 Card의 노출에 필요한 범위만 갱신한다. 과거 콘텐츠 승인 기록을 새 기능의 승인으로 승격하지 않는다.

## 확인한 동작

## 등록·검증 보완

새 Card를 지원하는 스키마 검사와 브라우저 소유 관계, 구조 편집 비활성 상태의 삽입 거부, 기존 v1 갤러리 검사를 함께 보완했다. 자체 텍스트 필드가 없는 구조형 Card에는 존재하지 않는 long-copy 상태를 만들지 않고 자식 텍스트의 기존 검증을 재사용한다. 관련 구조형 빈 상태의 양성/음성 검사도 추가했다.

Card 정의와 빈 시작점 2개만 추가하고, 품질 원장에는 미검토 상태로 등록했다. 과거 콘텐츠 승인 기록을 수정하거나 전체 콘텐츠를 승인하지 않았다. 카탈로그 구현과 등록 기록을 순차 통합할 때 이전 등록값을 잘못된 시점의 manifest와 비교하던 검사도 수정했다. 이전 값은 해당 등록 파일의 실제 Git revision manifest로 검증하고 현재 값은 현재 manifest와 일치해야 한다.

공유 CSS 원본 크기 상한은 유지했다. 기능 추가에 필요한 빌드 gzip 상한은 editor CSS 45,000→45,200 bytes, editor JS 507,000→507,500 bytes로 제한적으로 조정했다. 기존 파일 크기 부채 상한을 늘리거나 자동 baseline을 만들지 않았다.

테스트 초기 실패는 접힌 Outline, 라이브러리 진입 경로, 실제 검색/필수 필드 이름, 태블릿 버튼 선택자를 잘못 지정한 데서 발생했다. 실패를 성공으로 집계하지 않고 실제 UI 경로에 맞게 수정해 두 시나리오를 끝까지 실행했다.

- 브라우저: Card 2건, 구조·테마·중첩 드래그 6건, 생성/발행/복원 및 템플릿/중첩 생명주기 3건, 카탈로그 코드 4건, 텍스트/도구 조작 2건 통과.

- 성공한 브라우저는 입력과 runtime 연속성이 동일한 통합 재시도에서 재사용했다. 확인된 실패 이후 변경한 검사만 갱신했으며 전체 제품/콘텐츠 감사를 실행하지 않았다.

진척 원장은 UI5의 이 범위만 완료로 기록한다. CardGrid 전환·Hero/ImageText actions·다른 복합 블록의 내부 슬롯·완성 디자인 팩 및 운영 배포는 완료 범위가 아니다. 다음 고도화 후보는 Hero/ImageText actions이며 후속 차수의 범위 확정이 필요하다.




기존 v1 생명주기 검사에서 왼쪽 기본 라이브러리에 Card가 남아 있는 실제 노출 불일치를 발견해 수정했다. 전체 갤러리와 드래그 라이브러리 모두 구조 편집 비활성 상태에서 Card를 숨긴다. 단위 검사와 기존 문서 브라우저 검사에 양쪽 노출 계약을 명시했다. 전체 팩 등록 개수와 v1에서 실제 사용할 수 있는 개수를 구분한다.
