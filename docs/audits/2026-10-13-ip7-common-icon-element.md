# IP7 공통 아이콘 요소 구현과 검증

`media.icon`은 구성 이름과 무관한 공통 기본 요소다. 기존 카탈로그의 신뢰된 아이콘 23종을 사용하며 임의 SVG·HTML·실행 코드를 문서 입력으로 받지 않는다. 새 구성 데이터는 같은 편집기 빌드에서 이 요소를 조합할 수 있고, 블록별 편집기 등록을 요구하지 않는다. IP7 전체 완료 판정은 별도다.

## 구현 범위

문서 props는 `icon`, `label`, `decorative`다. 의미 있는 아이콘에는 눈에 보이는 문자가 포함된 설명을 요구한다. 장식용 아이콘은 접근성 트리에서 제외하되 기존 설명을 원본에 보존한다. 색상·크기·반응형 값은 기존 typed 스타일 계약을 사용한다. 새 Inspector는 공통 content 명령을 호출하며 Puck의 단일 Undo·저장 경로를 공유한다.

React 편집/미리보기와 PHP 출력은 기본 24px 및 지정된 크기·색상을 따른다. PHP는 기존 신뢰된 아이콘 출력기를 재사용한다. 독립 PHP 초안에는 생성 SVG를 포함하고, G7 공개 발행본에는 안전한 복원 마커만 제공한다. 공개 hydration은 명시적인 부모 크기 모드만 처리한다. 문서가 임의 마커 속성이나 실행 동작을 정의하지 않는다. 기존 아이콘 출력의 기본 모드는 변경하지 않는다.

공식 task `ip7-common-icon-element-20261013`은 기준 `71414ca21fe449c789158772d095e5eb88bc3ee0`에서 `shared-contract` lease와 정확한 파일 21개를 소유한다. 공유 문서 계약과 공개 runtime이 바뀌므로 제출·통합의 FULL 검사가 필요하다. G7 코어·기존 문서·운영 서버는 변경하지 않는다.

## 확인된 검사와 남은 검증

Node 24와 PHP 8.5.3의 직접 검사에서 Vitest 121개, TypeScript strict, PHPUnit 10개·637 assertions가 통과했다. TS/PHP는 같은 아이콘 수용·거부 fixture 8개를 사용한다. 23종 렌더, 의미 설명의 escaping, 빈 설명 거부, 임의 필드 거부, 공통 편집 명령과 반응형 원본 불변, 장식용/readonly Inspector, 공개 hydration의 안전한 크기 처리와 중복 실행을 포함한다.

독립 브라우저 시험은 빈 카탈로그 삽입, 의미·공통 스타일·모바일 편집, 단일 Undo/Redo, 주입 저장 포트 재열기와 23종의 세 폭 React/PHP 기하·색상·접근성 비교를 추가했다. 아직 실행 결과가 아니며 실제 서버 저장·발행 증거를 대신하지 않는다. 공식 제출 검사, Local 통합 및 설치형 저장·발행·G7 출력 후 아이콘 복원 시험을 이어서 수행한다. 통합된 공통영역 UI의 후속 증거 및 진척 원장·CHANGELOG 갱신은 해당 파일을 소유하는 별도 task에서 처리한다.

## 발행 경로의 SVG 회귀 보완

최초 제출 `8fc034dc1b84ecdca2b9eda131282e23e9167773`과 설치형 검증 제출 `d46c547c92754dca5cd0a9135a1b9a7939850b7f`의 결합 후보에서 아이콘의 UI 삽입·스타일·실제 저장·재열기까지 진행했으나 공개 미리보기 준비가 실패했다. 원인은 SVG를 발행 HTML에도 포함해 기존 `TemplateMarkupPolicy`의 금지 태그 검사를 통과하지 못한 제품 결함이다. 실패 증거는 `output/playwright/gates/integration-ip7-20261012/7104f021141b938d1e84bd07a0c4dcfff407de3017d0a6b0750aa5e02d472caa/c5a68cdb7b8c43e69a28535195bc4908/`에 보존한다.

기존 정책이나 G7 sanitizer를 변경하지 않고 독립 초안과 발행 출력의 표현만 분리한다. 회귀 시험은 실제 `HtmlCompiler`로 23종×세 shell을 컴파일하며, 수정 전 동일한 SVG 거부를 재현했다. 발행은 기존 안전한 마커를 사용하고 실제 브라우저의 SVG 복원·크기·색상·접근성 비교 기준은 유지한다. 이 보완의 단위·공식 재제출·브라우저 결과는 실행 후 판정한다.

최초 설치형 실행은 기존 12개 통과·새 아이콘 9개 실패로 종료했고, Local은 `59116bfa685959d5eb56bbedc629c8a6053eed12`로 원복됐다. 원래 활성 테마도 복구했다. 수정 후 `V3IconElementTest`, `CompilerCollaboratorsTest`, `DocumentV3CompilerTest`는 합계 25개·2,083 assertions와 Pint를 통과했다. 실제 `HtmlCompiler`의 69개 아이콘/shell 조합이 기존 금지 태그 정책을 통과한 결과이며, 수정 후 브라우저 검증은 별도로 남아 있다.
