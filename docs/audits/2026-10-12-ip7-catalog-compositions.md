# IP7 내장 구성 템플릿과 공통영역

상태: **구현 착수, 미완료**. 기준은 IP6 완료 SHA `2553987c1a08b544dff38a1f4cfe77599ea69254`다. 확정 스펙 SPEC-12·SPEC-13과 IND-07의 contract·browser·compatibility 증거를 모두 확보한 뒤 완료한다.

## 범위와 보존 경계

현재 내장 manifest의 모든 block과 preset을 열거하여 편집 가능한 구성·반복 템플릿·보호된 실행 기능·기존 원본 이행 경로를 대응시킨다. Hero·Card·ImageText뿐 아니라 반복·동적 블록과 PB Header/Footer를 포함한다. 대표 사례만 통과하거나 미구현을 지원 제외로 바꾸어 완료하지 않는다.

구성 템플릿의 삽입본은 PB 문서가 소유하는 요소 트리다. 내부 디자인은 기존 v3 명령·Puck 이력·정밀 Inspector로 편집하고, 서비스가 반환한 데이터와 인증·폼·슬라이더 등의 실행 책임은 디자인 원본과 분리한다. 공통영역은 본문과 별도 원본·revision을 유지한다.

기존 v1/v2·Site Part는 읽기만으로 전환하지 않는다. 사용자가 전환을 선택했을 때 원본 revision·알 수 없는 필드·블록별 매핑을 검사하고 초안 후보를 만든다. 미지원 데이터가 있으면 전체 전환을 중단하며 원본 snapshot·복원 경로와 마지막 정상 발행본을 보존한다. G7 소유 원본·코어·테마 파일·운영 배포는 변경하지 않는다.

## 작업 분할과 합격 조건

1. 전체 카탈로그·프리셋·Site Part의 필드/슬롯/동작을 조사하고 누락을 검출하는 계약과 대응표를 구현한다.
2. 필요한 v3 구성·반복·보호 동작 계약을 PHP/TS 공통 fixture로 연결한다. 계약 변경은 shared-contract lease 아래 별도 task에서 검증한다.
3. 기존 요소 편집·단일 이력에 구성 삽입과 내부 편집, 명시 전환·거부·복원을 연결한다.
4. 전체 대상의 저장/재열기 및 렌더 의미를 검증하고 실제 브라우저에서 내부 편집·Undo/Redo·공통 shell 미리보기를 확인한다.

task마다 정확한 파일을 claim하고 공식 제출·통합을 사용한다. 완료 전 실제 제출/통합 SHA·명령·결과·증거 경로를 이 기록과 진척 원장에 반영한다. 이 착수 기록 자체는 기능 구현 또는 검증 성공의 증거가 아니다.
