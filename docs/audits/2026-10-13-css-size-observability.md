# CSS 용량을 개발 차단 조건에서 제외

2026-10-13 사용자는 CSS 용량이 작업 중단의 병목이 되지 않도록 지시했다. 공개 CSS에 한정했던 측정 정책을 편집기·관리자·공통영역·모바일 내비게이션과 공통 기본 요소까지 적용한다. 원본 및 gzip 바이트를 기록하고 이전 상한 초과는 비차단 경고로 남긴다. 큰 임의 숫자로 상한을 옮기지 않는다.

CSS 파일의 존재·내용·문법과 import 소유권, 편집기에 관리자 전용 스타일이 섞이는 문제, 시각 회귀·실제 성능 검사는 계속 차단 조건이다. 이번 변경은 CSS를 추가하거나 전체 디자인·선택자·중복 스타일 규칙을 완화하지 않는다. 파일 분리와 최적화는 기능 구현 후 실제 측정과 유지보수 필요에 따라 수행한다.

`css-size-observability-20261013`은 기준 `59116bfa685959d5eb56bbedc629c8a6053eed12`의 정확한 파일 6개를 소유했다. 당시 실행 중인 아이콘 통합 후보나 다른 task의 파일은 수정하지 않았다. JS는 이미 승인된 두 편집기 512,000바이트 및 나머지 기존 기준을 유지한다.

검증은 이전 모든 CSS 상한을 초과하는 fixture의 정상 통과·실측 보고, JS 초과 거부, 누락/순환/import 경계·관리자 선택자 차단을 포함한다. 모바일 메뉴는 큰 CSS에서도 lint와 브라우저 명령을 실행하고 각각의 실패를 유지하는 격리 시험으로 확인한다. 격리 시험을 실제 제품 브라우저 통과로 보고하지 않는다.

직접 검사 `python3 -B -m unittest tests.Harness.test_frontend_budgets tests.Harness.test_content`의 56개와 `npm run typecheck`가 통과했다. Node 24를 사용했으며 실제 제품 브라우저 실행은 이 CSS 정책 검사에 포함하지 않았다.

공식 제출은 `74a77ba8af96b7c50d52904e37b976d51a8a71b1`이며, CSS 줄 수 경고 정책 `c5e4f0fc7703255cbb46b9f905ee777202eae56e`와 함께 `8ffe0698e70faba131ac017ada47156e58ba9a55`로 통합했다. 통합은 FULL 없이 관련 25개 gate를 통과했다. 경계 회귀·빌드 단위 2개·타입·521개 소스의 정적 검사를 포함하고, 입력이 같은 성공 검사는 재사용했다. 제품 소스 변경 없는 이 정책 작업 때문에 전체 제품 E2E를 반복하지 않았다.

후속 `css-browser-policy-record-20261013`은 독립 E2E의 마지막 45,200바이트 상한을 제거하고 비어 있지 않은 CSS·raw/gzip 실측 기록으로 맞춘다. 기존 CSS 내용·1px 출력 비교·상호작용 검사는 변경하지 않는다. 해당 시험 정의는 수집/타입 검사 대상이며, 아래 별도 아이콘 통합의 실제 브라우저 실행을 이 수정 후 재실행으로 표현하지 않는다. 변경 이력과 진척 기록도 같은 task에서 정합화하며 IP7은 진행 상태를 유지한다.
