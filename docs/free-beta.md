# G7 Page Builder 무료 베타 안내

페이지 생성 → 주소 지정 → 편집 → 미리보기 → 발행을 확인하는 개발 베타입니다. 정식 안정판이나 모든 G7 템플릿의 호환 인증을 의미하지 않습니다. 편집기는 PC에서 사용하고 공개 페이지는 PC·태블릿·모바일에서 확인합니다.

무료 범위는 편집기, 기본 블록, 페이지·추가 주소 관리, 헤더·푸터 편집, 기존 공식 무료 Page Kit, 회사 사이트 시작 킷입니다. 유료 후보인 전문서비스 킷은 무료 모듈 패키지에서 제외하고 별도 평가 ZIP으로 제공합니다. 구매한 디자인 구성도 무료 편집기로 계속 수정하는 방향이며 런타임 라이선스 만료를 추가하지 않습니다.

## 첫 사용

1. 단일 Ubuntu LTS VPS의 검증된 G7 환경에서 배포자가 제공한 사전 빌드 모듈을 설치·활성화합니다. DB·기존 모듈 파일을 백업합니다. 개발 소스만 올리거나 고객 서버에서 npm을 실행하지 않습니다.
2. 관리자 **페이지 빌더**에서 일반 페이지를 만들고 제목·주소를 지정합니다. 기존 G7의 **페이지 관리**는 그대로 유지됩니다.
3. 필요한 블록을 넣고 **저장 → 새로고침 → 미리보기 → 발행**합니다. 발행 전에는 추가 주소가 공개되지 않습니다.
4. 여러 페이지를 함께 시작하려면 **사이트 킷**에서 회사 사이트 시작 킷을 선택합니다. 각 페이지를 발행한 뒤 필요할 때 헤더·푸터 세트를 명시적으로 적용합니다.
5. 문의 기능을 사용하면 자신의 테스트 내용을 접수하고 관리자 문의함에서 확인합니다. 실제 운영 정보와 개인정보 안내는 운영자가 검토합니다.

## 확인할 환경과 한계

기준: PHP 8.5, G7 7.0.9, `sirsoft-basic 1.1.1`, 한국어, Page Builder 0.33.1 개발 빌드. 모듈 버전뿐 아니라 전달받은 Git SHA/빌드 식별자를 기록합니다. 현재 로컬 G7에는 작업 이력이 있으므로 stock G7 신규 설치 및 외부 VPS 합격으로 확대하지 않습니다.

사이트 주소 변경 후 다른 문서·메뉴의 링크는 자동으로 수정되지 않습니다. 홈 `/` 교체와 전체 테마 설치는 이 베타의 제공 범위가 아닙니다. 이를 후속 개발 차수로 확정한 것은 아니며, 현재 작업은 소스 저장소의 `docs/productization/editor-plan.md`에 기록한 편집 고도화 실행계획을 따릅니다. G7 기능 선택은 설치된 모듈의 공개 capability에 따라 달라집니다. 구매·결제·재다운로드 계정 시스템은 이 베타에 포함하지 않습니다.

문제가 생기면 마지막 정상 발행본을 먼저 확인하고, 공통영역은 기존의 정상 발행 세트를 다시 적용합니다. 모듈을 임의로 비활성화하면 자체 공개 주소도 사라질 수 있습니다. 복구용 백업을 유지합니다.

## 평가와 문제 보고

평가자는 도움 없이 페이지 1개와 킷 1개를 설치·수정·발행하고, 막힌 단계·걸린 시간·오류 문구·사용 환경을 기록합니다. 화면 증거에서 개인정보를 지웁니다. 접수 채널은 배포자가 안내하며 지원 응답 시간은 아직 보장하지 않습니다.

자동 검사·개발자 브라우저 확인은 외부 제작자의 사용성 합격을 대신하지 않습니다. 무료 베타 공개일, 외부 평가 결과, 정식 판매 조건은 별도로 기록합니다.
