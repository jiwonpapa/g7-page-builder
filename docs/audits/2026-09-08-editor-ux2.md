# 독립 PB 개선 2차

상태: 구현 및 재현 검사 진행 중. 운영 미배포.

기준: `90a6b67804593aa73f98a8112f04b7659ca5453f`.

Hero 반응형 정렬·글자 비율과 슬라이더 요약만 대상으로 한다. 저장 계약·콘텐츠는 변경하지 않는다. 실제 브라우저 증거 확인 후 완료 기록을 갱신한다.

## 변경 전 실제 브라우저 재현

기준 코드에서 로컬 Chromium으로 직접 조작했다. 태블릿 right/balanced는 center/18px로 남았고, 모바일 left/compact는 center/16.875px로 남았다. 슬라이더 요약에 `<strong>혜택</strong> &amp; 안내`가 그대로 노출됐다. 증거: `output/playwright/ux2-baseline`, `/tmp/g7pb-ux2-baseline.log`. 초기 시험 fixture 타입/선택자와 preview 뒤 최신 lock 재조회는 시험 연결 오류로 별도 교정했다.

구현은 편집기 전용 반응형 정렬/비율 selector 12개의 적용 대상을 실제 내용 요소로 옮기고, 슬라이더 요약만 inert template에서 텍스트로 읽는다. 원문·컴파일러·공개 CSS는 변경하지 않았다. CSS 한도는 180,077/180,100 bytes로 유지한다.
