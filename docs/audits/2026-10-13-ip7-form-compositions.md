## 제작 기준

- 시각: 흰 단일 표면, 충분한 간격, 읽기 쉬운 라벨과 명확한 입력 경계, 제출 동작 하나의 강조색을 사용한다.
- 내용: 제목·짧은 안내 → 필수/선택 입력 → 개인정보 동의 → 제출·상태 순서다. PC/태블릿 2열, 모바일 1열이며 독자가 DOM 순서 그대로 이동한다.
- 상호작용: 기존 기본 요소 선택·직접 입력·Inspector·단일 Undo를 사용한다. 공개 문의의 입력·접수 피드백만 사용하고 장식용 모션이나 별도 동작 코드를 추가하지 않는다.

## 소스 검증
