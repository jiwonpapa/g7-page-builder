# IP7 문의 rate limit 카운터 분리

G7 7.1.0 설치형 브라우저 시험에서 세 출력 모드의 폼 치수 비교와 CSRF 준비를 통과한 뒤 정상 문의가 429로 거부됐다. 기존 PB 문의 route의 접두사 없는 `throttle:10,1`은 Laravel의 domain/IP 키를 다른 접두사 없는 API와 공유한다. 일반 화면/API 조회만으로 문의 허용 횟수가 소진될 수 있었다.

PB Provider의 해당 route에만 `g7pb_inquiry` 접두사를 지정한다. 분당 10회, web/CSRF 보호, 검증과 문의 저장은 그대로다. IP 변경·캐시 초기화·제한 상향·미들웨어 제외·G7 코어 수정으로 시험을 통과시키지 않는다.

회귀 시험은 독립 ArrayStore에서 같은 익명 IP의 일반 API 25회와 문의 10회를 교차 실행하고, 두 카운터의 분리와 11번째 문의의 거부를 검사한다. 설치 환경 캐시·운영 데이터는 변경하지 않는다. 실제 브라우저 접수 수용은 공식 Local 통합에서 별도로 판정한다.
