## 제공한 편집 기능

- **아이콘:** 기존 제공 아이콘 11종, 크기 3종, 의미 색상 3종. 장식은 접근성 트리에서 숨기고 의미 전달은 1~120자의 접근성 이름을 받습니다.
- **목록:** 독립 `content.list-01@1`, 순서/비순서 한 단계, 1~20항목, 항목당 일반 문구 200자. 캔버스에서 한글 문구를 직접 편집하고 기존 Puck 반복 항목 도구로 복제·순서 변경·삭제 및 Undo/Redo를 사용합니다.
- **배지:** 일반 문구 1~40자, 선택 아이콘, 크기·의미 색상. 문구는 캔버스에서 직접 편집하며 링크나 동적 상태 동작을 갖지 않습니다.
- 기본 요소는 기존 5종에서 **8종**입니다. root, Section, Columns의 열, Stack에 각 위치의 기존 제한 안에서 삽입합니다. 기본 요소 자체에 자식 슬롯을 추가하지 않습니다.
- 기존 RichText와 IconList의 ID·원본을 보존했습니다. RichText는 혼합 문서이며 별도 목록 타입은 후속 카드에서 본문과 목록의 의미 역할·개수 제한을 구별하기 위한 계약입니다.
- `PageBuilderDocument` v1/v2와 새 block version 1을 연결했습니다. 내장 Pack 0.16.0, 최소 builder 0.34.0입니다. 제품 세 버전 파일은 0.34.0으로 일치하며 릴리스 배포는 하지 않았습니다.
- 내장 정의 **48종**, 프리셋 **98종**, 호환 전용 HeroSplit을 제외한 삽입 후보 **145개**입니다. 기본 요소 탭은 정의 8개와 예제 12개로 20개입니다.

## 입력·저장·출력 경계

길이는 Unicode 문자 수입니다. 임의 SVG·HTML·JavaScript·클래스·style 필드·자식 슬롯을 열지 않습니다. 기존 불완전 초안 저장 정책을 유지하며 미리보기·발행 컴파일에서 내용 유효성을 검사합니다.

G7/Laravel이 빈 문자열을 null로 정규화하므로 장식 아이콘의 빈 이름과 배지의 선택 아이콘은 null도 명시적 비움으로 읽습니다. 키 누락과 의미 전달 아이콘의 비어 있는 이름은 그대로 거부합니다. 불완전 초안의 미리보기·발행 준비는 422이고 마지막 정상 발행본은 유지됩니다.

편집/발행의 공통 의미 스타일을 연결했습니다. 신규 기본 요소의 root 가로 여백과 `Section → Columns → Stack → leaf`의 안쪽 여백을 일치시켰습니다. 후자는 기존 제목까지 함께 검증합니다. 도구 테두리와 편집 안내는 발행 결과에 포함하지 않습니다.

## 발견 후 수정한 문제

- G7의 빈 문자열 → null 정규화 때문에 기본 배지의 미리보기가 실패했습니다. 선택값만 호환하고 필수 의미 이름/키 누락 거부를 유지해 수정했습니다.
- 신규 기본 요소의 root 가로 여백과 중첩 Stack의 공개 세로 여백이 편집 화면과 달랐습니다. 실제 계산 스타일 비교와 화면 확인을 함께 추가했습니다.
- 카탈로그 확장 후 기존 갤러리 수 고정값과 품질 검사 대상 수가 뒤처졌습니다. 실제 manifest/정책에 따라 후보를 계산하며 성능·품질 기준은 유지했습니다.
- 테스트는 실제 Puck의 일반 텍스트 편집, 표시된 radio label·select option, Outline 선택을 사용합니다. 제품 동작을 우회하거나 skip으로 통과시키지 않았습니다.
- 썸네일 검증이 이전 CSS 빌드를 읽는 순서 오류는 `6c21af80bb2c43bc2fd3833a2fdd2582ec069aa2`에서 수정했습니다. block/preset 출처 비교는 후보 빌드 확인 뒤 실행하며 네 phase에서 순서를 검증합니다.
- 실패했던 실행 로그와 화면은 보존합니다. 최종 합격은 위 성공 실행에만 근거합니다.
